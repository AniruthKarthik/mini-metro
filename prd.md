The project aims to develop an AI/ML-based autonomous agent capable of playing and achieving high scores in Mini Metro by continuously analyzing the evolving transportation system and constructing an optimal or near-optimal metro network for the current game state. The central problem is formulated as a dynamic network-optimization problem: given the currently available stations, their types and locations, passenger demand, geographical constraints, available metro lines, locomotives, carriages, bridges, tunnels, interchanges, and other limited resources, the agent must determine the network configuration that is expected to maximize long-term passenger throughput, minimize congestion, prevent station overcrowding, extend survival time, and ultimately maximize the game score. Since Mini Metro allows the game to be paused while the network is modified, the agent can periodically freeze the simulation, remove some or all existing metro lines, reconsider the network globally, construct a new optimized configuration, allocate available trains and resources, and then resume gameplay with the redesigned network. This allows the project to focus not only on incremental decisions but also on repeatedly solving a global network-design problem as the environment changes. The agent must learn when an existing network should be preserved, locally modified, or completely reconstructed and should account for the long-term consequences of each configuration rather than simply responding to the station with the highest immediate congestion. The project may investigate and compare traditional graph algorithms, graph-theoretic heuristics, combinatorial optimization, classification, regression, clustering, demand forecasting, graph neural networks, reinforcement learning, evolutionary algorithms, search techniques, learned value functions, and hybrid ML-optimization approaches for generating and evaluating candidate metro networks. Historical and current gameplay states can be used to learn relationships between network topology, passenger demand, resource allocation, congestion, survival, and eventual game performance, allowing learned models to estimate the expected value of alternative configurations and guide the search toward increasingly effective designs. During gameplay, the agent should repeatedly observe changes such as the appearance of new stations, shifts in passenger demand, developing bottlenecks, and the acquisition of additional resources, determine whether re-optimization is necessary, generate or search through alternative network configurations, select the configuration with the highest predicted long-term value, rebuild or modify the network while the simulation is paused, and continue this optimize–execute–observe–reoptimize cycle until the game ends. The system should be trained and evaluated across many game sessions and different network states to determine whether it can learn general strategies rather than memorizing particular layouts, with performance measured using average and maximum game score, passengers successfully transported, survival time, congestion frequency, average waiting time, resource utilization, computational optimization time, consistency across unseen states or maps, and improvement over random, greedy, manually designed, rule-based, and conventional graph-heuristic baselines. The ultimate objective is to create an autonomous machine-learning agent that can beat Mini Metro by learning how to repeatedly solve its evolving network-design problem, intelligently reconstructing the transportation network as conditions change and discovering strategies that outperform simpler algorithms and eventually strong human gameplay.
